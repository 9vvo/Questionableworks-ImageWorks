# Keyboard shortcuts

Cmd on macOS, Ctrl on Windows and Linux. Only commands that work are listed.

## File

| Shortcut | Command |
| --- | --- |
| Cmd+N | New… |
| Cmd+O | Open… |
| Cmd+W | Close |
| Cmd+S | Save |
| Cmd+Shift+S | Save As… |
| Cmd+Alt+Shift+W | Export As… (PNG or JPEG) |
| F12 | Revert |
| Cmd+Q | Quit |

## Edit

| Shortcut | Command |
| --- | --- |
| Cmd+Z | Undo |
| Cmd+Shift+Z | Redo |

## Layer

| Shortcut | Command |
| --- | --- |
| Cmd+Shift+N | New Layer |
| Cmd+J | Duplicate Layer |
| Cmd+G | Group Layers |

## View

| Shortcut | Command |
| --- | --- |
| Cmd+= | Zoom In |
| Cmd+- | Zoom Out |
| Cmd+0 | Fit on Screen |
| Cmd+1 | 100% |
| Cmd+scroll, or pinch | Zoom at the pointer |
| Scroll, or two-finger drag | Pan |

## Tools

| Key | Tool |
| --- | --- |
| H | Hand. Hold Space for the Hand tool temporarily; the middle mouse button also pans |
| Z | Zoom. Click to zoom in, Alt-click to zoom out |
| R | Rotate View. Drag to rotate; hold Shift to snap to 15° |

## Layers panel

| Gesture | Effect |
| --- | --- |
| Click | Select a layer |
| Cmd-click | Add to or remove from the selection |
| Shift-click | Select a range |
| Double-click a name | Rename (Enter to finish, Esc to cancel) |
| Drag | Move the selected layers; drop on the middle of a group to put them inside it |
